### Define the Data Management Approach
- Data Warehouse - Medallion approach  
### Medallion Approach
#### Bronze Layer
- Raw, unprocessed data
- Tables
- Debugging
- No Transformations to data
- No Modeling
#### Silver Layer
- Clean and standardized data
- Tables
- Prepare for Analysis
- Cleaning Data
- No Modeling
#### Gold Layer
- Business-Ready Data
- Views
- Prepare for reporting and Analytics
- Business Transformations
- Data Model needed(Star, Constellation, etc.)
